# CBS Crypto Recruiting Database

Master database of recruiting targets for George's Columbia MBA (Class of 2028), covering the
crypto/digital-asset M&A, corporate development, and venture capital lanes. Built August 22, 2026 —
the week before orientation.

## The file

**`CBS_Crypto_Recruiting_Database.xlsx`** is the single working file. It extends the original
recruiting tracker with four new sheets and keeps every original sheet intact.

| # | Sheet | What it holds |
|---|-------|---------------|
| 1 | **Master Targets** *(new)* | All 47 targets in one sortable view. Priority / Status / Next Step are live formulas mirroring the three lane tabs — edit status there, not here. |
| 2 | IB Targets | 23 advisory firms in three tiers (OCR / Direct / Network) with deal evidence and access channels. Yellow columns F–M are the working columns. |
| 3 | Corp Dev Targets | 9 buy-side corp dev teams (Kraken, Coinbase, Stripe, Ripple, Mastercard, Robinhood, Circle, Figure, Talos). |
| 4 | VC Targets | 15 priority funds for the venture lane. |
| 5 | VC Fund Database | Full-fidelity detail on 42 funds from the Aug 2026 NYC research: fund lineages, founders, LPs, theses, portfolios, caveats. |
| 6 | **People Directory** *(new)* | 57 named individuals across all lanes — role, background, engagement channel, personal/Columbia tie. Verify each on LinkedIn before outreach (yellow columns to log it). |
| 7 | Target Profiles | Depth per target: hiring reality, entry route, timing, watch items. |
| 8 | **Personal Angles** *(new)* | 13 CV assets mapped to the targets they open — the one-liner, how to use it, and the confidentiality cautions. |
| 9 | League Table | Disclosed crypto M&A advisor mandates, Jan 2024 – Aug 2026. |
| 10 | Deal Evidence | 48 transactions with full advisor attributions. |
| 11 | **Engagement Feed** *(new)* | 25 hooks — podcasts, newsletters, research, conferences, and CBS-cycle actions — with cadence and priority. |
| 12 | Timeline | The CBS Class of 2028 recruiting calendar with moves per window. |

## How to use it weekly

1. Work the **yellow columns** on the three lane tabs (and People Directory / Engagement Feed) —
   contacts, status, next steps. The Master sheet and header counts update automatically.
2. Check **Engagement Feed** "Now" items first: club fair, CVF (~Aug 28), IBC resume book,
   Architect Partners alerts.
3. Before any outreach, pull the target's row in **Target Profiles** and your line in
   **Personal Angles**; verify the person in **People Directory** on LinkedIn.
